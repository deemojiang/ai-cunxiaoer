二、关键数据流（六步办事 + RAG）

用户(语音/文字/图片)→ ASR / OCR→ 意图识别→ RAG 检索 · Function Calling→ LLM 生成→ 生单 / 答复 / 跳转→ TTS 播报 · 消息推送

识别 → 确认 → 采集 → 摘要 → 生单 → 反馈；日常问答（天气/百科）直接答复不生单，紧急安全跳采集立即生单，复杂问题转人工。

为什么每村只要 ¥986？（拆解验证，非笔误）

这是三件事叠加的直接结果，非计算错误：① DeepSeek 单价极低（¥3/¥6 每百万 tok）；② 日活仅 200（1 万注册里约 2%）；③ 每轮输入 4,000 tok。逐层验证：

  • 每日活/天：3 会话 × 6 轮 = 18 次调用 → 输入 72,000 tok、输出 9,000 tok
  • 每日活/天成本 = 72,000/1M×¥3 + 9,000/1M×¥6 = ¥0.216 + ¥0.054 = ¥0.27/人·天
  • 200 DAU × 365 天 × ¥0.27 ≈ ¥19,710/年（20 村） ÷ 20 = ¥986/村

敏感度：换 GLM-5.2 约 ¥3,646/村；若 RAG 上下文更重（高档 5,000 tok/轮 + 更高日活），DeepSeek 升到约 ¥3,364/村。真正的成本杠杆是日活规模与每轮上下文长度。

四、分阶段基础设施部署预算（前 / 中 / 后期）

硬件按 3 年直线折旧计入年化预算。前期纯 API → 中期自建单机(并发已提至 5×，100-250)+API → 后期 GPU 集群。

API 预算口径说明（为何和“纯 API 版”差很多）

下表中/后期的“商业 LLM API”是自建扛主力推理后的残余调用（兜底/灾备/尝鲜），非全量走 API。若全量走 API：20 村 ≈¥2 万/年、全县 ×10 ≈¥19.7 万/年（第三章）——与前期 API ¥2 万一致；中/后期迁到本地后才降到 ¥1 万 / ¥3 万。两者口径不同，非计算错误。

4.1 三阶段定位

阶段部署形态并发目标适用规模驱动因素
前期纯商业模型 API按量弹性首批 20 村、低-中日活零 capex、快速上线

4.2 并发测算模型（价格能否扛这些并发）

参数取值说明

解码上限并发≈ 60 / 卡= 1,500 ÷ 25
扣 RAG prefill + TTFT 后~25–35 / 卡prefill 抢算力，需降额

结论：2× H20 ≈ 50–70 可持续并发，“并发 20–50”没低估。价格已按 2026 行情上修：H20 96G 单卡 ¥10–14 万，2 卡 + 整机 ≈ ¥30–42 万（此前 ¥20–30 万偏低、确实买不到）。

卡型更新（2026）

消费级旗舰已是 RTX 5090（32G GDDR7），此前的 4090 已过时；但 5090 单卡 32G 低于旧“4090 48G 改”，大模型需更多卡。数据中心侧 H20 96G 仍是中国合规主力（后续特供 Blackwell 如 B30 系列）。政府/乡村项目常要求信创国产化，建议同时评估华为昇腾 910B/910C。

何时该自建（盈亏平衡逻辑）
  • 纯省钱不成立：前期 API（20 村中档）仅 ≈¥2 万/年，远低于自建单机（基础 ≈¥20 万、5× ≈¥56 万）。
  • 自建真正驱动：数据合规与出域可控、峰值并发保障、规模化后边际成本、信创国产化。
  • 平衡点：全县高活跃时（全量走 API：DeepSeek 高档 ≈¥67 万、GLM ≈¥251 万），本地集群（≈¥153 万/年）在成本与自主可控上占优；中期单机是合规与过渡折中，并发按需在基础/5× 间取舍。

五、测算备注与风险

  • 仅含对话 LLM 推理；Embedding 向量化 < ¥500/年已忽略；ASR/TTS/图像/搜索按调用另计。
  • 成本与 DAU、会话数、每轮上下文长度近似线性；RAG 注入上下文越长，输入成本越高。
  • GLM-5.2 采用 Z.AI 折算价，国内 bigmodel 实际费率可能不同；DeepSeek 为官方直采价；最终以签约价为准。
  • 价格为 2026-07 快照，模型厂商调价频繁，上线前请复核实时费率。
  • GPU 卡型 2026 口径：消费级 RTX 5090（32G）、数据中心 H20 96G（或特供 Blackwell）、信创评估昇腾 910B/910C；capex/运维随卡型、机房、人力、是否国产化浮动，为规划区间，招采前须以实时报价为准。
